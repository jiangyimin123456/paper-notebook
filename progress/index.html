备份与同步

完整备份

备份包含所有课题、进展、截图与历史版本。浏览器数据可能被清理，请定期下载备份。复制网页文件不会带走浏览器里的笔记。

电脑间同步

课题记录使用独立同步文件，沿用文献笔记的方式：记录先保存在本机，再同步至你指定的私有 GitHub 仓库。截图一并同步。页面打开并解锁期间自动同步。本模块可使用已有 paper-notebook-data 私有仓库；进展保存在独立的 progress-v1.json，不会混入文献笔记。需要在本模块配置并解锁一次。

尚未连接 · 本机记录可正常使用

首次连接方法
  1. 在 GitHub 创建私有仓库 paper-notebook-data，添加 README。
  2. 创建 Fine-grained token，仅授权这个数据仓库，Contents 选择 Read and write。
  3. 在本页输入令牌与本机解锁密码。每台电脑分别配置，不要把令牌发到聊天里。
