尚未连接 · 本机记录可正常使用

首次连接方法
  1. 在 GitHub 创建私有仓库 paper-notebook-data，添加 README。
  2. 创建 Fine-grained token，仅授权这个数据仓库，Contents 选择 Read and write。
  3. 在本页输入令牌与本机解锁密码。每台电脑分别配置，不要把令牌发到聊天里。
